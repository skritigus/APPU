# Лабораторные работы по АПЦУ

Лабораторные сдаются на Vivado2018.2 [ссылка на скачку](https://rutracker.org/forum/viewtopic.php?t=5582621). Для запуска лабораторной требуется:
1. Создать новый проект.
2. В соответствующие пути (необязательно, но желательно) установить файлы для соответствующей лабораторной.
3. Добавить файлы в проект (тестбенчи в симуляцию, обычные модули в дизайн).
4. Запустить симуляцию для теста, чтобы убедиться в работоспособности.
